# What is this:

The repository contains a library for simple addition, subtraction, multiplication, division, checking if the number is even and hex to rgb converted´r. The server.js file runs the first 4 calculations on randomized integers between 1 and 10. The two numbers are decided at the start of running main.<br>

The testing file is for Chai and check that the main.js works as intended, using Unit Testing basics with assert commands.

# Before starting:

### Initialize

npm init -y

### Add Dependencies

npm install --save-dev mocha chai

### Install express

npm install express

## To use software:

### To Run tests from the root or inside the folder

npm run test

### To Run Server code from root

node src/server.js
