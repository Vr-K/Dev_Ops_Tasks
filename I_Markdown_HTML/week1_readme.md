# Readme for week1.py task

### 1) Purpose of the project:

The readme is based on an on old first year project file. At this point I was still learning to code in Python.<br>
The program opens a CSV file and goes through it tagging how many weekdays there are in it.

### 2) Process

1) Program starts
2) Requests file name and format in style of name.format. *example: A7_T3_D2.csv*
3) reads csv files in format:
    - *Weekday;Hour;Consumption(kWh);Price(€/kWh)*
4) Gives the number of weekdays on the csv file
5) Ends analysis and ends program

### 3) Install instructions

No specific instructions, CSV comes preinstalled with Python. Simply run the code. Be sure to have the CSV files in same folder as the program.<br><br>

### 4) Usage examples

For reading if the first field in the CSV file has one of the weekdays as part of it. Monday to Sunday. Though, this is more of an task to learn how to read and go through CSV files than anything useful.

### 5) Who maintains the project

The project is finished as it is and stable as a Python code. CSV protocol is maintained by IETF and will propably be around as long as python itself will be. I believe it is all rather standard and unchanging so it will be stable forever and ever.
