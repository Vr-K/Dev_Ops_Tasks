
# What is this:

The repository contains a library for simple addition, subtraction, multiplication, division and checking if the number is even. The main.js file runs the first 4 calculations on randomized integers between 1 and 10. The two numbers are decided at the start of running main.<br>

The testing file is for Chai and check that the main.js works as intended, using Unit Testing basics with assert commands.

# Before starting:

### Initialize

npm init -y

### Add Dependencies

npm install --save-dev mocha chai

## To use software:

### To Run tests from the root or inside the folder

npm II - Unit testing\test    <!-- running the whole test folder -->
<br>
or
<br>
npm test

### To Run Main code from the root or inside the folder

node II - Unit testing\src\main.js
<br>
or
<br>
node src\main.js
